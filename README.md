# Vec2 Maths Library 📐

A lightweight, header-only 2D vector math library for C++. 

This project provides a simple and intuitive `Vec2` struct to handle 2D coordinates and common vector mathematics. It is built to be easily dropped into game engines, physics simulations, or any project that requires clean 2D spatial calculations.

## 🚀 Features

*   **Operator Overloading:** Easily add, subtract, multiply, and divide vectors just like regular numbers (`v1 + v2`, `v1 * 2.0f`).
*   **Vector Math:** Built-in functions for calculating Magnitude (length), Normalization, and Dot Products.
*   **Linear Interpolation (Lerp):** Smoothly transition between two points.
*   **Debugging Utilities:** Includes a `toString()` function to easily print and format coordinates.
